# AutoRecord

Windows용 녹화·웃음 감지·클립 편집 앱입니다.

## 설치

[최신 릴리즈](https://github.com/yeongjo/AutoRecord/releases/latest)에서 `AutoRecord_*_x64-setup.exe`를 받아 설치하세요. Windows 11을 권장합니다.

앱은 실행 시와 매시간 새 버전을 확인하고 서명된 업데이트를 자동 다운로드합니다. 다운로드가 끝나면 **업데이트 후 재시작** 버튼이 나타납니다. 녹화·분석·내보내기 작업 중에는 설치가 차단됩니다.

이 저장소는 설치 파일과 업데이트 정보만 배포합니다. 사용자 녹화와 프로젝트는 업로드하지 않습니다.

첫 릴리즈는 별도 PC에서 아직 검증되지 않았으며, Windows 코드 서명 인증서가 없어 SmartScreen 경고가 나타날 수 있습니다.
